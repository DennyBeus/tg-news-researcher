# tg-news-researcher

Система ежедневных Telegram-дайджестов на базе n8n и Python-парсера.

## Что делает

- Парсит Telegram-каналы по расписанию
- Фильтрует новости по интересам с помощью AI (GPT-4o)
- Отправляет ежедневный дайджест с краткими описаниями через Telegram-бота
- Генерирует посты в вашем стиле на основе выбранных новостей

## Стек

- **n8n** — оркестрация, Telegram-бот, AI-запросы, работа с БД
- **Python** — только парсер Telegram-каналов (kurigram)
- **PostgreSQL** — хранение новостей, каналов, интересов, стилей, настроек
- **OpenAI API** — фильтрация, суммаризация, генерация постов

## Структура

- `parser/` — Python-парсер (вызывается n8n через Execute Command)
- `n8n/` — JSON-файлы workflow для импорта в n8n
- `sql/` — SQL-скрипты для создания таблиц в БД
- `PROJECT.md` — полная документация и архитектура проекта
